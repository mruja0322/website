photography
HTML · CSS · JavaScript · no build step, no dependencies

A static photography portfolio with a small built-in print shop -- just index.html, style.css, script.js and an images/ folder.

  • Genre filter chips, live search and collapsible sections that all build themselves from a single photo list, so adding work needs no markup changes.
  • Full-screen viewer with arrow keys, swipe, zoom and pan, next/prev, a counter and a Share button.
  • Shop flow choosing digital or a framed print in A4/A3/A2, a shortlist that survives a page reload, and one combined WhatsApp message at checkout.
  • Ships with a PowerShell dev-server script and GitHub Pages instructions, and follows the visitor's system theme with a manual override.

Hospital Management System
Python · Flask · MySQL · Jinja templates

A hospital management system with a Flask backend over a MySQL database (medicore_hms) and server-rendered HTML templates.

  • Centralised query helper built on MySQL dictionary cursors, with explicit commit control and recursive conversion of dates, times and timedeltas into JSON-safe values.
  • Introspects the live schema to adapt to each table's allowed MySQL ENUM values instead of hard-coding them, with case-insensitive matching.
  • Database credentials are read from a DB_PASSWORD environment variable, and the app refuses to connect rather than falling back to a blank password.
